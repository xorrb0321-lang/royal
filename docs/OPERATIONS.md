# 운영 가이드

## 필수 규칙

1. **로그아웃 금지** — 오픈채팅은 공식 백업 대상이 아니며, 로그아웃 시 PC 로컬 대화가 사라집니다.
2. **방 퇴장 금지** — 퇴장 시 해당 방 대화가 삭제됩니다.
3. **보내기 주기** — 2~3시간마다 또는 하루 2~4회 각 방에서 `Ctrl+S` 보내기.

##보내기 방법 (PC)

```
오픈채팅방 → 우측 ≡ → 대화 내용 → 대화보내기
또는 채팅방에서 Ctrl+S
→ exports 폴더에 저장
```

## 프로그램 동작

- `exports/` 폴더에 새 `.txt`가 생기면 자동 파싱
- Instagram 프로필 URL만 추출 (`username`)
- 중복 username은 스킵
- `output/instagram_accounts.csv` 갱신

## 폴더 구조

```
프로젝트/
  exports/          ← 카카오보내기 저장 위치
  output/
    instagram_accounts.csv
  data/
    state.db
```

## 실시간이 아닌 이유

이 프로그램은 카카오 **공식보내기 파일**만 읽습니다.
보내기 전에 올라온 메시지는 다음보내기 때 수집됩니다.
